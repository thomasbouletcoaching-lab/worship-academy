# Worship Academy

La meilleure formation de piano de louange : passer de « je voudrais servir par la musique » à « j'accompagne la louange en autonomie ».

- **Formation** : `content/` (fiches Markdown, trois niveaux, transversal). Sommaire : `docs/CURRICULUM.md`.
- **Application** : Vite + React + TypeScript, PWA en cours. Moteur de théorie testé dans `src/theory/`.

## Lancer

```bash
npm install
npm run dev      # serveur de développement
npm test         # tests unitaires (théorie, parseurs, rendu)
npm run build    # build de production (dist/)
```

## Documents

- `docs/FORMAT.md` : contrat d'une fiche
- `docs/DECISIONS.md` : décisions prises
- `docs/PROGRESS.md` : avancement
- `docs/BLOCKERS.md` : blocages et contournements
